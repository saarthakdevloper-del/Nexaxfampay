API Documentation

Complete reference for UPI QR Generate and Payment Verification APIs

Payment Flow

  1. Call the QR Generate API with your api_key. The response contains the order_id and qr_url.
  2. Show the image at qr_url to your customer. The customer scans it with any UPI app and pays.
  3. Collect the UTR (FamPay/BharatPe) or Order ID (Paytm) from the customer after payment.
  4. Call the Verify Payment API with the api_key and reference. You'll get the payment status.

QR Generate API (All Gateways)

This API is the same for all gateways (FamPay, Paytm, BharatPe). Only the api_key changes.

Endpoint (Dynamic QR — customer enters the amount)

GEThttps://gozovip.xyz/api/qr?api_key=YOUR_API_KEY

Endpoint (Fixed Amount QR)

GEThttps://gozovip.xyz/api/qr?api_key=YOUR_API_KEY&amount=100

Parameters

api_key (required)FAM_xxx / PAY_xxx / BHP_xxx
amount (optional)Amount in ₹ (if not provided, a dynamic QR is generated)

Success Response

{
    "status": "success",
    "data": {
        "order_id": "GRAM6D417B14",
        "qr_url": "https://gozovip.xyz/api/qr_img?data=upi%3A%2F%2Fpay%3Fpa%3Dyou%40fam%26am%3D100",
        "upi_id": "paytm.s1zxmoz@pty",
        "gateway": "paytm",
        "amount": "0",
        "created_at_ist": "12-10-2026 11:37:45",
        "expires_at_ist": "12-10-2026 11:42:45"
    },
    "dev": "@ANUJxCODER"
}

Error Response

{
    "status": "error",
    "message": "Invalid api_key",
    "dev": "@ANUJxCODER"
}

FamPay — Verify Payment API

Endpoint

GEThttps://gozovip.xyz/api/verify?api_key=FAM_xxx&utr=UTR

Parameters

api_key (required)FamPay API key (FAM_xxx)
utr (required)12-digit UTR from customer

Success Response

{
    "status": "success",
    "data": {
        "utr": "628533319832",
        "transaction_id": "FMPIB6775198710",
        "amount": 1,
        "sender_name": "ANUJ PATEL",
        "payment_time_ist": "12-10-2026 11:54:19"
    },
    "dev": "@ANUJxCODER"
}

Error Response

{
    "status": false,
    "message": "Transaction not found",
    "data": { "utr": "628533319832" },
    "developer": "@ANUJxCODER"
}

Paytm — Verify Payment API

Endpoint

GEThttps://gozovip.xyz/api/verify?api_key=PAY_xxx&orderid=ORDER_ID

Parameters

api_key (required)Paytm API key (PAY_xxx)
orderid (required)Order ID from QR response

Success Response

{
    "success": true,
    "status": "TXN_SUCCESS",
    "transaction_id": "GRAM6D417B14",
    "amount": 1,
